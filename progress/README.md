# progress/

Handoff-файлы между стадиями. Когда контекст приближается к 60-80% — сохраняешь состояние и делаешь `/clear`.

## Формат

Имя: `<task>-handoff.md`. Шаблон: [../templates/handoff.md](../templates/handoff.md).

## Что внутри handoff

- **Stage** — на какой стадии остановились (research / spec / plan / phase-N)
- **What's done** — что уже сделано в этой сессии
- **What's next** — что делать в новой сессии
- **Artifacts** — ссылки на созданные файлы (research, spec, plan)
- **Open questions** — нерешённые вопросы, развилки
- **Context pointers** — какие файлы открыть первыми в новой сессии (progressive disclosure)

## Когда писать handoff

- Контекст > 60%.
- Переход между стадиями (research → spec, spec → plan, plan → impl).
- Конец рабочего дня, продолжать будешь завтра.
- Перед переключением на другую задачу.

## Правила

- Handoff ≤ 150 строк. Это передача состояния, не пересказ кода.
- Всегда указывать пути к артефактам, не копировать их содержимое.
- После записи handoff → `/clear` → новая сессия начинается с чтения этого файла.
