# thoughts/research/

Research-артефакты (Stage 1 Bulletproof). Исходники перед spec.

## Формат

Имя: `YYYY-MM-DD-task.md`. Шаблон: [../../templates/research.md](../../templates/research.md).

## Что внутри

- **Findings from codebase** — что нашли параллельные Explore-агенты (структура, паттерны, зависимости, тесты)
- **WebSearch findings** — кто уже решал эту задачу, best practices, библиотеки
- **Alternatives** — 2-3 подхода с плюсами/минусами
- **Recommendation** — **обязательный финальный раздел**. Какое решение выбрано и почему.

## Правила

- Режим **read-only**. Никакого кода на этой стадии.
- Параллельные под-агенты: 1 агент на 1 область (структура / паттерны / зависимости / тесты).
- Артефакт ОБЯЗАН заканчиваться разделом **Recommendation**. Список опций без вывода — не research.
- После завершения — `/clear` и переход к spec с ссылкой на research-артефакт.
