# Research: Промокод за подписку в соцсетях

**Дата:** 2026-05-15  
**Статус:** Research завершён  
**Контекст:** Нужно дать пользователям возможность получить промокод (PRO trial) в обмен на подписку в Instagram и Telegram  
**Каналы:** Telegram бот + сайт (millio-web)

---

## 1. Постановка задачи

Цель: **growth-хак** — расширить аудиторию в соцсетях, одновременно дав пользователям возможность протестировать PRO.

Flow в одном предложении:
> Пользователь подписывается на TG-канал и/или Instagram Millio → подтверждает это → получает Apple Offer Code → активирует PRO trial в приложении.

---

## 2. Технические ограничения (критично)

### Instagram API — МЁРТВ с декабря 2024
Instagram Basic Display API **полностью deprecated 04.12.2024**. Автоматически проверить, подписан ли пользователь на аккаунт — невозможно. Никакого публичного метода в Graph API для проверки followers нет.

**Вывод:** Instagram верификация = только honor-system (доверие без проверки) или скриншот + ручная модерация.

### Telegram — РАБОТАЕТ
`getChatMember(chat_id, user_id)` возвращает статус подписки. Бот должен быть администратором канала. Проверка мгновенная, автоматическая.

### Apple Offer Codes — текущий стандарт
Promo codes в App Store Connect заменены **Offer Codes** (StoreKit 2):
- **Unique codes** — одноразовые (например, `MILLIO-XYZABC`) — идеальны для раздачи
- **Custom codes** — многоразовые (например, `MILLIOFRIEND`) — для масс-кампаний
- Активируются через `presentCodeRedemptionSheet()` (iOS 16.3+) или ссылкой `apps.apple.com/redeem`
- Генерируются в App Store Connect → Subscriptions → Offer Codes
- **Лимит:** до 150,000 уникальных кодов на подписку в квартал

## 3. Рекомендуемая архитектура

### Вариант A — TG Bot (рекомендуется как MVP)

```
Пользователь               TG Бот                    Millio Backend
     │                        │                             │
     │──── /start ───────────▶│                             │
     │                        │──── getChatMember() ───────▶│ (проверка подписки на @millio_app)
     │                        │◀─── "member" ───────────────│
     │                        │──── POST /promo/issue ──────▶│ (выдать уникальный код)
     │                        │◀─── { code: "MILLIO-XYZABC" }│
     │◀── "Твой код: ..." ────│                             │
     │                        │                             │
     │── (переходит в App Store, активирует PRO) ──────────▶│
```

**Компоненты:**
1. **TG Бот** (`@millio_promo_bot` или похожий) — Node.js / Python / Grammy.js
2. **Backend эндпоинт** `POST /promo/issue` — выдаёт уникальный код из предзагруженного пула
3. **Таблица в БД** `promo_codes` (code, issued_at, telegram_user_id, redeemed)
4. **Anti-abuse:** один telegram_user_id = один код (проверка по БД)

### Вариант B — Сайт (дополнительно)

На сайте `milliomoney.ru` — лендинг-блок:
```
[Подпишись на TG] ── кнопка открывает @millio_app → после подписки
[Подпишись на Instagram] ── honor-system (без проверки)
[Получить код] ── открывает TG бота, который проводит верификацию
```

Сайт не верифицирует сам — только перенаправляет в бота. Вся логика — в боте.

## 4. Детальный flow (рекомендуемый)

### Шаг 1: Точка входа
- **TG:** кнопка в описании канала `@millio_app` → `/start` бота
- **Сайт:** блок "Получи PRO бесплатно" → кнопка → `tg://resolve?domain=millio_promo_bot`

### Шаг 2: Бот встречает пользователя
```
Привет! 👋 Получи 30 дней PRO бесплатно.

Шаг 1: Подпишись на @millio_app
Шаг 2: Нажми "Я подписался"
```

### Шаг 3: Верификация TG
- Бот вызывает `getChatMember(@millio_app, user.id)`
- Если `status = "member"` → переходим к шагу 4
- Если `status = "left"` → "Ты ещё не подписан. Подпишись и попробуй снова."

### Шаг 4: Бонус за Instagram (honor-system)
```
Получи дополнительно продление до 60 дней!

Подпишись на @millio.app в Instagram и нажми "Я подписался"
```
Без проверки — выдаём код с бОльшим сроком или просто благодарим. Риск минимален (раздаём тестовый доступ, а не деньги).

### Шаг 5: Выдача кода
```
🎉 Твой промокод: MILLIO-X7K2P9

Нажми "Активировать" → откроется App Store
```
Кнопка-ссылка: `https://apps.apple.com/redeem?ctx=offercodes&id=<bundle_id>&code=MILLIO-X7K2P9`

### Anti-abuse
- Один TG user_id = один код (проверяем по БД перед выдачей)
- Если уже выдан: "Ты уже получил код: MILLIO-X7K2P9"
- Rate limiting на `/promo/issue` по IP (сайт) и user_id (бот)

## 5. Instagram — что реально делать

Поскольку автоверификация невозможна, три стратегии:

| Стратегия | Сложность | Эффект |
|-----------|-----------|--------|
| **Honor-system** — просто просим подписаться, верим на слово | Минимальная | Конверсия выше, риск minimal (тестовый доступ) |
| **Скриншот в бота** — пользователь присылает скриншот подписки | Средняя | Ручная модерация, не масштабируется |
| **Не делать Instagram** — только TG (автоверификация) | Нет | Чище UX, но теряем Instagram аудиторию |

**Рекомендация:** Honor-system для Instagram. Мотивация подписаться есть (получают бонус), а риск мошенничества незначителен — мы раздаём тестовый доступ, не деньги.

## 6. Стек реализации

### Telegram Bot
- **Grammy.js** (TypeScript) — современный, хорошо интегрируется с NestJS
- Или **python-telegram-bot** — проще для standalone сервиса
- Деплой: отдельный контейнер рядом с бэкендом (уже есть Docker Compose)

### Backend (NestJS — уже есть)
Новый модуль `promo/`:
```
src/promo/
  promo.module.ts
  promo.service.ts        # логика выдачи, anti-abuse
  promo.controller.ts     # POST /promo/issue
  promo-code.entity.ts    # Prisma schema
```

Prisma schema:
```prisma
model PromoCode {
  id             String   @id @default(cuid())
  code           String   @unique
  issuedAt       DateTime?
  telegramUserId String?  @unique  // anti-abuse: 1 user = 1 code
  redeemed       Boolean  @default(false)
  pool           String   @default("default")  // для сегментации (TG/Instagram/site)
}
```

### Frontend (millio-web — уже есть)
Новый блок в лендинге — `PromoSection`:
- Кнопки "Подписаться" на TG и Instagram
- Кнопка "Получить код" → открывает бота
- Счётчик выданных кодов (social proof, опционально)

## 7. Что нужно подготовить в App Store Connect

1. Создать **Subscription Offer** типа "Free Trial" или "Pay Up Front" для PRO
2. Сгенерировать пул **Unique Offer Codes** (например, 1000 штук)
3. Загрузить CSV с кодами в БД бэкенда
4. Проверить flow через Sandbox environment

**Важно:** Apple Offer Codes работают только для **новых подписчиков** (или тех, кто никогда не был PRO). Для существующих пользователей нужна отдельная логика (или просто честный disclaimer).

## 9. Риски и митигация

| Риск | Вероятность | Митигация |
|------|------------|-----------|
| Пользователь отписывается после получения кода | Высокая | Ок, цель — рост аудитории в моменте; кодов ограниченное количество |
| Коды кончатся | Средняя | Алерт в Sentry при `pool_remaining < 50`; быстрое пополнение в App Store Connect |
| Abuse через множество TG аккаунтов | Низкая | 1 user_id = 1 код; можно добавить cooldown по времени регистрации аккаунта |
| Apple отклонит flow | Очень низкая | Offer Codes — официальный механизм Apple, всё по правилам |
| Instagram honor-system злоупотребления | Низкая | Мы дарим тестовый доступ, не деньги — риск приемлем |

## 10. Что не делать (из исследования)
