# Smart Data Reset

Экран: `Профиль -> Умная очистка данных`.

## Что умеет

- Очистка по периоду:
  - весь период;
  - последние 30/90/365 дней;
  - кастомный диапазон дат.
- Выбор целей очистки:
  - операции (`CashflowTransaction`);
  - операции по счетам (только связанные со счетами операции, сами счета остаются);
  - обнуление счетов в периоде (счета остаются, их суммы приводятся к нулю);
  - кешбэк (`Cashback`);
  - счета (карты/кредиты/инвестиции + `FinanceAccount` + `FinanceGroup`);
  - категории (cashflow + cashback);
  - настройки приложения (`SettingsManager` + состояние `AppState`).
- Режим полного сброса (все цели сразу).

## Важная семантика

- Период применяется только к операциям и кешбэку.
- Для «операций по счетам» период тоже применяется.
- Если очистка операций/операций по счетам запускается на «Весь период», сервис дополнительно
  перепривязывает исторические baseline-значения счетов к их текущему состоянию
  (`initialBalance`, `initialRemainingAmount`, `initialAmount`), чтобы в динамике и дневных срезах
  не оставались «призрачные» суммы из удаленной истории.
- Для «обнуления счетов в периоде» создаются парные корректировки:
  - на конец выбранного периода (обнуление);
  - на следующий день (восстановление состояния после периода).
  Счета и названия не удаляются.
- При удалении счетов дополнительно удаляются:
  - связанные транзакции (по `cardID/toCardID/creditID/investmentID`);
  - кешбэки, которые были привязаны только к удаляемым картам.
- При очистке категорий выполняется безопасная миграция:
  - custom-категории cashflow в транзакциях переводятся в `other`;
  - custom-категории cashback в записях кешбэка переводятся в `other`.

## Согласованность UI после очистки

После применения очистки сервис публикует события:

- `FinanceEvent.cardsUpdated`
- `FinanceEvent.creditsUpdated`
- `FinanceEvent.transactionsUpdated`
- `FinanceEvent.auditSnapshotsUpdated`
- `BackupEvent.restoreCompleted`

Это принудительно обновляет подписанные вьюмодели, чтобы UI не оставался со старым кэшем.

Также при очистке, затрагивающей финсчета (операции/операции по счетам/обнуление/удаление счетов),
очищается `finance.balance.audit.snapshot.store` в `UserDefaults`, чтобы ручные snapshot-правки не
конфликтовали с новым состоянием данных.

## Локализация экрана

- Тексты экрана Smart Data Reset централизованы в `millio/UI/Profile/SmartDataResetLocalization.swift`.
- Поддерживаются RU/EN через `Locale` (без смешения языков на одном экране).
- Для защиты от регрессий добавлен тест `SmartDataResetLocalizationTests`.
