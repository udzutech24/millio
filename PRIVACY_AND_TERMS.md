## 1. Политика конфиденциальности

### 1.1. Общие положения

Millio ("Приложение", "мы", "нас") уважает вашу конфиденциальность и обязуется защищать ваши персональные данные. Данная Политика конфиденциальности описывает, как мы собираем, используем, храним и защищаем информацию при использовании нашего мобильного приложения.

**Принцип Offline-First:** Приложение спроектировано для работы преимущественно в офлайн-режиме. Все ваши данные хранятся локально на вашем устройстве и не передаются на наши серверы без вашего явного согласия.

### 1.2. Какие данные мы собираем

#### 1.2.1. Данные, которые вы вводите

Приложение позволяет вам вводить и хранить следующие типы данных:

- **Финансовая информация:**
  - Информация о банковских картах (номер, тип, банк, валюта, баланс, кредитный лимит)
  - Финансовые транзакции
  - Данные о кредитах и займах
  - Информация о кешбэке

- **Персональные настройки:**
  - Выбранный язык интерфейса
  - Настройки резервного копирования
  - Предпочтения отображения валют

- **Данные для трекинга:**
  - Привычки
  - Статистика потребления воды (если используется)

**Важно:** Все эти данные хранятся **только на вашем устройстве** в локальной базе данных SwiftData.

#### 1.2.2. Данные, собираемые автоматически

- **Техническая информация:**
  - Версия iOS
  - Версия приложения
  - Идентификатор устройства (для резервного копирования)

- **Данные о курсах валют:**
  - Приложение получает актуальные курсы валют из публичных API (Open ER API, Frankfurter)
  - Эти данные кэшируются локально для офлайн-работы
  - Мы не передаем ваши персональные данные в эти сервисы

#### 1.2.3. Данные iCloud (опционально)

Если вы включите функцию резервного копирования:

- Ваши данные будут синхронизироваться с вашим личным iCloud аккаунтом
- Используется **только Private CloudKit Database** — ваши данные доступны только вам
- Мы не имеем доступа к вашим данным в iCloud
- Резервное копирование полностью опционально и может быть отключено в любой момент

### 1.3. Как мы используем ваши данные

#### 1.3.1. Локальное хранение

- Все данные хранятся локально на вашем устройстве в зашифрованном хранилище iOS (sandbox)
- Данные доступны только вам и только на вашем устройстве
- Приложение работает полностью офлайн и не требует постоянного подключения к интернету

#### 1.3.2. Резервное копирование (опционально)

- Если вы включите резервное копирование, ваши данные будут сохранены в вашем личном iCloud аккаунте
- Резервное копирование происходит автоматически при уходе приложения в фоновый режим
- Вы можете в любой момент отключить резервное копирование в настройках
- При восстановлении данных они полностью заменяют локальные данные (snapshot-стратегия)

#### 1.3.3. Шифрование (опционально)

- Вы можете включить дополнительное шифрование резервных копий
- Шифрование использует AES-GCM алгоритм
- Ключи шифрования хранятся в защищенном хранилище iOS Keychain
- Мы не имеем доступа к вашим ключам шифрования

#### 1.3.4. Обновление курсов валют

- Приложение периодически обновляет курсы валют из публичных API
- Обновления происходят только при наличии интернет-соединения
- Мы не передаем ваши персональные данные в эти сервисы
- Курсы валют кэшируются локально для офлайн-работы

### 1.4. Передача данных третьим лицам

**Мы НЕ передаем ваши персональные данные третьим лицам.**

Исключения:

1. **Apple iCloud (только при включенном резервном копировании):**
   - Данные хранятся в вашем личном iCloud аккаунте
   - Используется Private CloudKit Database
   - Мы не имеем доступа к этим данным
   - Соблюдаются условия использования Apple iCloud

2. **Публичные API курсов валют:**
   - Open ER API (https://open.er-api.com)
   - Frankfurter (https://api.frankfurter.app)
   - Мы передаем только запросы на получение курсов валют
   - Ваши персональные данные не передаются

### 1.5. Безопасность данных

#### 1.5.1. Локальная безопасность

- Все данные хранятся в защищенном хранилище iOS (sandbox)
- Доступ к данным имеет только ваше приложение
- Данные защищены системой безопасности iOS

#### 1.5.2. Безопасность резервных копий

- Резервные копии хранятся в вашем личном iCloud аккаунте
- Используется Private CloudKit Database
- Опциональное шифрование с использованием AES-GCM
- Ключи шифрования хранятся в iOS Keychain

#### 1.5.3. Безопасность передачи данных

- Все сетевые запросы используют HTTPS
- Данные передаются только при резервном копировании (если включено)
- Мы не используем сторонние аналитические SDK

### 1.6. Ваши права

В соответствии с GDPR и другими применимыми законами о защите данных, вы имеете право:

1. **Право на доступ:** Вы можете просмотреть все ваши данные прямо в приложении
2. **Право на исправление:** Вы можете редактировать ваши данные в приложении
3. **Право на удаление:** Вы можете удалить все данные, удалив приложение с устройства
4. **Право на переносимость:** Вы можете экспортировать ваши данные через резервное копирование в iCloud
5. **Право на отзыв согласия:** Вы можете отключить резервное копирование в любой момент

### 1.7. Хранение данных

- Данные хранятся на вашем устройстве до тех пор, пока вы не удалите приложение
- Резервные копии в iCloud хранятся до тех пор, пока вы не отключите резервное копирование или не удалите данные из iCloud
- При удалении приложения все локальные данные удаляются
- Резервные копии в iCloud остаются до их ручного удаления

### 1.8. Изменения в политике конфиденциальности

Мы можем периодически обновлять данную Политику конфиденциальности. О существенных изменениях мы уведомим вас через приложение или по электронной почте (если вы предоставили адрес).
