# Spec: Account Quick Audit

**Статус:** ГОТОВ К РЕАЛИЗАЦИИ  
**Дата:** 2026-05-16  
**Размер:** M (3-4 файла)

## WHAT

Флоу «быстрой актуализации баланса» — пошаговая проверка всех счетов одним за другим. Пользователь запускает из настроек финансов и проходится по каждому счёту: подтверждает баланс или редактирует прямо там же.

## WHY

Счетов много (карты + кредиты + инвестиции). Сейчас актуализация = зайти в каждый счёт вручную → найти редактирование → сохранить. Долго и скучно. Quick Audit = один флоу, все счета подряд, минимум тапов.

## UX

### Запуск
Кнопка «Актуализировать балансы» в `FinancesSettingsSheet` → открывает `fullScreenCover`.

### Флоу
1. **Intro-экран** (0.3с): «Проверка счетов» + иконка + кнопка «Начать». Счётчик «7 счетов».
2. **Карточка счёта**: появляется с spring-анимацией снизу.
   - Иконка (emoji/bank), название, тип (Карта / Кредит / Инвестиция)
   - Текущий баланс — крупно
   - Progress bar + «3 из 7»
3. **Действия на карточке**:
   - Кнопка **«Верно ✓»** (зелёный акцент) → счёт сохранён (timestamp updated), анимация slide-out влево, следующая карточка
   - Кнопка **«Изменить ✏️»** → TextField появляется на карточке поверх баланса (spring), цифровая клавиатура. Кнопка «Сохранить» → сохраняет и переходит дальше.
4. **Свайп-поддержка**: свайп вправо = верно, свайп влево = редактировать.
5. **Outro-экран** (после последнего счёта): анимация ✓ + «Все счета проверены!» + haptic `.success` + confetti-эффект (встроенный через частицы). Кнопка «Готово» закрывает флоу.

### Визуальный стиль
- Dark mode, glassmorphism (как везде в приложении)
- Карточка: rounded 24pt, background `.ultraThinMaterial`, цвет акцента от типа счёта
- Анимации: `spring(response: 0.5, dampingFraction: 0.75)` для slide-in
- При подтверждении: карточка улетает вправо с rotation (-5°)
- При редактировании: карточка остаётся, баланс «трансформируется» в TextField

## Acceptance Criteria

- [ ] Кнопка в FinancesSettingsSheet запускает флоу
- [ ] Все типы счетов поддержаны: Card (balance), Investment (amount), Credit (remainingAmount)
- [ ] Изменения сохраняются сразу в SwiftData при нажатии «Сохранить»
- [ ] «Верно» не изменяет баланс, но можно добавить `lastVerifiedAt` timestamp (optional)
- [ ] Свайп работает для обоих действий
- [ ] Анимации spring на появление и исчезновение карточки
- [ ] Haptic feedback: `.light` на каждый шаг, `.success` в финале
- [ ] Outro с celebratory анимацией
- [ ] Пустое состояние: если счетов нет — сообщение
- [ ] Кнопка «Закрыть» на любом этапе

## Out of scope (v1)

- Добавление нового счёта в флоу
- Пропуск отдельных типов счетов
- История аудитов
