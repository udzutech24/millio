# Spec: Процентный доход по вкладам

**Date:** 2026-05-02
**Stage:** 2 / Spec
**Research:** [`thoughts/research/2026-05-02-deposit-interest.md`](../thoughts/research/2026-05-02-deposit-interest.md)

## Problem

Тип "Вклад" в приложении — пустышка: в пикере написано "срок, ставка, проценты", но при создании открывается стандартный редактор Investment без этих полей. Пользователь не может указать % ставку, срок вклада и автоматически планировать ежемесячный процентный доход в Cashflow.

## Goal

Сделать так, чтобы вклад имел % ставку, срок и мог автоматически добавлять плановый ежемесячный доход (категория "Проценты") в Cashflow.

## Scope

- Поля вклада: ставка % годовых, дата открытия, дата закрытия (опционально)
- Расчёт планового ежемесячного дохода: `amount × rate / 100 / 12`
- Тоггл "Планировать доход в Cashflow" — создаёт recurring income (monthly, категория .interest)
- При изменении суммы или ставки — плановый доход пересчитывается
- При архивации вклада — связанная scheduled-транзакция удаляется
- Локализация новых строк (RU/EN/zh-Hans)

## Non-Goals

- Автоматическое создание фактической транзакции по истечении срока — вне scope
- Новая SwiftData-модель Deposit — не нужна, расширяем Investment

## Acceptance Criteria

- [ ] AC1: При создании/редактировании вклада (`isDeposit = true`) в редакторе видна секция "Процентный доход" с полями: ставка (% годовых), дата открытия, дата закрытия
- [ ] AC2: Плановый ежемесячный доход рассчитывается автоматически и показывается в UI: `amount × rate / 100 / 12` (округлено до 2 знаков)
- [ ] AC3: Тоггл "Планировать доход в Cashflow" — при включении создаётся scheduled income (monthly, категория Проценты, сумма = плановый доход)
- [ ] AC4: При изменении суммы или ставки — linked scheduled transaction обновляется автоматически
- [ ] AC5: При архивации или удалении вклада — linked scheduled transaction удаляется
- [ ] AC6: Все новые строки локализованы в Localizable.xcstrings (ru/en/zh-Hans)
- [ ] AC7: `isDeposit = true` проставляется автоматически при создании через пикер (preset: .deposit)
- [ ] AC8: На экране динамики вклада (FinanceDynamicsView) видны: полоса параметров (ставка/срок/прогресс), блок прогноза дохода (ежемесячный/за срок/накоплено/осталось), строка следующего поступления (если Cashflow включён)
- [ ] AC9: На графике динамики — пунктирная линия прогнозного дохода (нарастающий % к балансу)
- [ ] AC10: Редактор вклада поддерживает выбор типа капитализации (без/ежемесячная) и пересчитывает реальный доход с учётом сложного процента
- [ ] AC11: Блок прогноза отображает ориентировочный НДФЛ если доход превышает необлагаемый лимит (ключевая ставка ЦБ × 1 млн ₽)
- [ ] AC12: Уведомление за N дней до окончания вклада (пользователь задаёт N: 7/14/30 дней)

## Constraints

- **Стек:** SwiftUI + SwiftData + Swift Concurrency
- **Модель:** Lightweight migration (новые поля опциональны или имеют default) — явная миграция не нужна
- **God-VM:** CashflowViewModel (4598 строк) — точечные изменения только через конкретный метод, не трогать всё подряд
- **Dark Mode only**
- **Файлы >500 строк:** InvestmentEditorView, CashflowViewModel — читать только нужные диапазоны

## Edge Cases

- Ставка = 0% → плановый доход = 0, тоггл disabled (нет смысла планировать 0)
- Дата закрытия < дата открытия → валидация, показать ошибку
- Вклад архивируется → linked scheduled transaction удаляется, даже если тоггл был включён
- Пользователь меняет сумму вклада → плановый доход пересчитывается и linked transaction обновляется
- `depositLinkedScheduledID` указывает на несуществующую транзакцию → graceful fallback (создать новую или игнорировать)
- Восстановление из backup → `depositLinkedScheduledID` может указывать на несуществующую транзакцию в новом устройстве → не краш

## Open Questions

- Как округлять: `floor`, `round`, или до 2 знаков? → round до 2 знаков (банковский стандарт)
- Нужна ли капитализация в v1? → Нет (Non-Goals)
