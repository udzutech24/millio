# Spec: Custom Rate Source

**Slug:** custom-rate-source  
**Дата:** 2026-05-23  
**Статус:** УТВЕРЖДЁН  
**Размер:** M

---

## WHAT

Добавить в пикер источников курсов новый вариант — «Свой курс». Пользователь вводит курсы вручную для своих избранных валют. Для всех остальных пар приложение прозрачно падает обратно на следующий источник в цепочке (millio/erapi/cbr).

---

## WHY

Часть пользователей работает с нерыночными курсами: внутренний корпоративный курс, обменник, банковский курс продажи. Они хотят видеть портфель в тех числах, с которыми реально работают — а не в рыночных.

---

## Acceptance Criteria

- [ ] В пикере источников появляется карточка «Свой курс»
- [ ] На карточке — кнопка «Редактировать» (только для `.custom`)
- [ ] В редакторе: список избранных валют пользователя, текстовые поля с числовым вводом, формат «X [primary] за 1 [foreign]»
- [ ] Курс USD обязателен если primary ≠ USD (валидация + объяснение)
- [ ] После сохранения редактора — `currencyRateSourceDidChange` перезапускает перерасчёт везде
- [ ] Пока custom-курс не задан → карточка показывает «Не настроен», выбрать нельзя
- [ ] Если custom выбран и пользователь очистил курс → автоматический откат на `.millio`
- [ ] Для пар, которых нет в custom-таблице, прозрачный fallback на следующий источник в цепочке
- [ ] Все новые строки локализованы (RU / EN / zh-Hans)
- [ ] Widget: корректно обрабатывает rawValue `"custom"` (не падает, показывает custom-курсы или fallback)
- [ ] `DataResetService.reset()` очищает custom-курсы

```

│ Ручной ввод                                   │

```
Кнопка «Редактировать» видна всегда на custom-карточке (не только при выборе).

**Редактор (sheet):**
- `NavigationStack` с заголовком «Свой курс»
- Строки: флаг + код + TextField (числовой) + «[primary]»
- USD-строка обязательна если primary ≠ USD, выделена сноской
- Кнопка «Сохранить» (disabled пока USD не заполнен при необходимости)

## Хранение

`CustomRateStore` (UserDefaults):
- Ключ `"custom_rates"` → `[String: Double]` где значение = «сколько primaryCurrency за 1 foreign»
- Ключ `"custom_rates_primary"` → `String` (для которой primary были сохранены — на случай смены primary)

Конвертация в USD-base (для `CurrencyRateService.cachedRates`):
```
usdInPrimary = storedRate["USD"] если primary ≠ USD, иначе 1.0
cachedRates[code] = storedRate[code] / usdInPrimary
```

---

## Интеграция в CurrencyRateService

В `setRateSource(.custom)`:
- Вместо `cachedRates = ["USD": 1.0]` — загружаем custom-таблицу (конвертируем в USD-base)
- `refreshRates()` для `.custom` — noop (ничего не грузим из сети)
- `buildFallbackChain()` при `.custom` — `.custom` первый, остальные как обычно (для пар без custom-курса)

В `getRate(from:to:)`:
- Если `rateSource == .custom` и пара есть в cachedRates → возвращаем
- Если пара отсутствует в custom-таблице → fallback через `globalFiatDaily` источник (как у `.cbr` для non-RUB пар)

---

## Out of scope

- Конвертер: custom-курс можно выбрать как converter override через существующий механизм (он уже работает)
- Исторические курсы: custom не поддерживает historical (нет данных по датам)
- Криптовалюты: вне scope этой фичи
- iCloud sync custom-курсов: v1 — только локально
