# Spec: Financial Rain — анимация запуска приложения

**Date:** 2026-05-23
**Stage:** 2 / Spec
**Research:** [`thoughts/research/2026-05-23-launch-animation.md`](../thoughts/research/2026-05-23-launch-animation.md)

## Problem

Текущий launch screen (`LaunchingView`) показывает статичную картинку `LaunchImage` со скромным параллакс-сдвигом и shimmer на логотипе. Это технически работает, но визуально не запоминается и не передаёт DNA продукта (финансы, движение данных, цифры).

## Goal

Добавить анимацию "финансового дождя" — падающие колонки финансовых символов и цифр — как фоновый слой launch screen, создающий яркий брендовый момент без изменения существующей логики (хаптики, wordmark, spinner).

## Scope

- Новый SwiftUI-компонент `FinancialRainView` — изолированный, без внешних зависимостей
- Интеграция в `LaunchingView` как фоновый ZStack-слой поверх `SplashBackdropView`
- Поддержка `accessibilityReduceMotion` — при включённой опции анимация не запускается
- Символьный набор: `₽ $ € ¥ % ↑ ↓ + − 0 1 2 5 8 k m .`
- Дождь начинается сразу при появлении экрана, плавно затухает по мере появления логотипа
- **Easter egg — скрытая фраза:** через ~0.8s в дожде горизонтально "всплывает" фраза, локализованная по языку приложения:
  - EN: `SAVE & GROW`
  - RU: `КОПИ И РАСТИ`
  - zh-Hans: `储蓄成长`
  Фраза держится ~0.6s, потом растворяется обратно в шум. Ключ в `Localizable.xcstrings`: `launch.rain.message`

## Non-Goals

- SpriteKit, SceneKit, Metal — только SwiftUI (`TimelineView` + `Canvas`)
- Изменения в хаптиках, логике lifecycle, шиммере логотипа
- Интерактивность (тапы, жесты)
- Сохранение состояния между запусками

## Acceptance Criteria

- [ ] **AC1** — анимация видна при запуске на физическом устройстве и симуляторе (не менее 5 падающих колонок)
- [ ] **AC2** — при `accessibilityReduceMotion = true` анимация не запускается (статичный экран)
- [ ] **AC3** — анимация не конкурирует с логотипом: общая прозрачность слоя ≤ 0.35
- [ ] **AC4** — frame rate не падает ниже 60 fps на iPhone 12 и новее (проверить в Simulator)
- [ ] **AC5** — компонент `FinancialRainView` изолирован: предпросмотр `#Preview` работает без `AppState`
- [ ] **AC6** — существующие тесты `LaunchingView` (если есть) остаются зелёными
- [ ] **AC7** — `reduceMotion`-ветка покрыта unit-тестом или snapshot-тестом

## Constraints

- **Стек:** SwiftUI-only, `TimelineView` + `Canvas`, Swift Concurrency для seed-инициализации
- **Производительность:** `Canvas` для batch-рендера всех символов одним draw call; не использовать `ForEach` + отдельные `Text` для каждого символа
- **Минимальный деплой-таргет:** iOS 17 (уже есть в проекте)
- **Цвета:** только через `AppColors`, не хардкодить hex

## Edge Cases

- `reduceMotion = true` → статика, анимация не стартует
- Очень маленький экран (SE) → columns должны адаптироваться к ширине GeometryReader
- Долгий launch (загрузка CloudKit) → rain продолжает идти без обрывов; не ограничен по времени
- Быстрый launch (< 0.5s) → анимация успевает хоть немного проиграть (не мигает)

## Open Questions

- Нужно ли менять `LaunchImage` или оставить как фон под дождём? → оставляем, rain поверх
- Цвет символов: зелёный (Matrix-канон) или AppColors.accent? → решается в Phase 1, prefer AppColors
