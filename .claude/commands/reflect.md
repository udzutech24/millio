Завершение сессии. Выполни строго по шагам:

## Шаг 1. Рефлексия

Создай файл `.business/история/YYYY-MM-DD-<краткое-название>.md` по шаблону [templates/reflection.md](../../templates/reflection.md). Заполни все 8 секций:

1. Задача (исходный запрос)
2. Как решалась
3. Решена ли (полностью / частично / нет)
4. Эффективно ли (честно)
5. Было → Стало
6. **Идеи по улучшению** — пройди по 4 осям (агенты, токены, процесс, бизнес)
7. Артефакты и коммиты
8. Что для следующей сессии

## Шаг 2. Continuous Improvement (промт #15)

Для каждой оси, где есть наблюдение — создай файл в `improvements/<категория>/YYYY-MM-DD-<slug>.md` по соответствующему шаблону из `improvements/templates/`:

- Агент дал плохой ответ / не использовал нужный инструмент → `improvements/agents/`
- Жёг контекст / токены → `improvements/tokens/`
- Процесс споткнулся → `improvements/process/`
- Факт про бизнес → `improvements/business/`

**Правило:** конкретика, не общие слова. Если наблюдений нет — так и напиши «0 наблюдений», не выдумывай.

## Шаг 3. Актуализация плана

Если работали с `plans/*.md` — обнови:
- Статус (`НЕ НАЧАТ` / `В РАБОТЕ` / `РЕАЛИЗОВАН` / `ЗАБЛОКИРОВАН`)
- Состояния фаз `[ ]` / `[~]` / `[x]`
- Журнал изменений

## Шаг 4. Отчёт

Короткий отчёт пользователю:
- Файл рефлексии: путь
- Сколько идей зафиксировано в improvements/ и в каких категориях
- Какие планы актуализированы
