# Лишнее чтение skill-файла при ревью плана

**Дата:** 2026-06-07
**Категория:** tokens/context

## Наблюдение

При ревью плана `finance-balance-contract` был прочитан нерелевантный файл `skill-creator/SKILL.md` вместе с нужным `bulletproof/SKILL.md`. Это не сломало задачу, но сожгло контекст на информацию, не связанную с ревью плана.

## Диагноз

Причина — параллельный batch был собран слишком широко перед проверкой списка навыков. Для задач ревью плана достаточно читать только явно применимый skill и сами артефакты spec/plan.

## Как оптимизировать

- Перед batch-чтением skill-файлов проверять, что каждый файл соответствует выбранному skill.
- Для ревью планов по умолчанию читать `bulletproof` + `spec` + `plan`; остальные skill-файлы только по явному триггеру пользователя.

## Ожидаемый эффект

Меньше шумного контекста в начале сессии и ниже риск, что нерелевантные инструкции повлияют на вывод.
