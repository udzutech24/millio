# Regression Tests Must Make Competing Sources Diverge

## Наблюдение

В задаче с рассинхроном баланса часть regression-тестов изначально была слабой: live-значение и replay-значение совпадали, поэтому тест мог проходить даже при неправильной ветке исполнения.

## Правило

Если баг связан с выбором между двумя источниками данных, тест обязан делать эти источники различными. Иначе тест проверяет только совпавший результат, а не правильный путь данных.

## Применение

- Для live vs replay: задавать разные `amount/balance` и `initialAmount/initialBalance`.
- Для bypass guard: делать live-result отличным от replay-result.
- Комментарий fixture должен соответствовать фактическим данным теста.
