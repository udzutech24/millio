# Cold start time — наблюдение и базовая метрика

**Дата:** 2026-05-11  
**Источник:** логи симулятора, запуск build 51

## Наблюдение

```
Lifecycle decision finished in 2239 ms
initializeColdStart finished in 6318 ms
```

Cold start занимает **~6.3 секунды** (симулятор). Из них ~2.2с — `AppLifecycleUseCase.initialize` (auth refresh + CloudKit status + iCloud check параллельно).

## Оценка

- 6.3с на симуляторе — нормально (симулятор медленнее устройства по сети).
- На реальном устройстве с iCloud + CloudKit + auth refresh — ожидаемо 3–4с.
- **Риск:** если в будущих фазах добавить ещё один синхронный шаг в lifecycle — может дотянуть до 8–10с на слабом устройстве.

## Что делать

- Отслеживать метрику после каждого релиза (Crashlytics custom metric или просто проверять лог).
- При росте `initializeColdStart` выше 8000 ms на симуляторе — расследовать, какой шаг добавился.
- Кандидат на оптимизацию: `iCloud status refresh finished in 2646 ms` — самый долгий шаг; можно перевести в lazy (показывать backup-статус не при старте, а при открытии ProfileView).
