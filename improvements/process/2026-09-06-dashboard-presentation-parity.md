# Проверять полный путь финансовой цифры до виджета

Дата: 2026-09-06. Источник: текущие `RootTabView.swift:524`, `CashflowHeroPresentation.swift`, `CashflowSummaryWidget.swift:167`.

Факт: основной Cashflow исключает переоценку из потока операций, Dashboard добавляет её; форматтер Dashboard теряет отрицательный знак. Локальное исполнение извлечённого форматтера подтвердило `-1234 → 1 234`.

Процедура: при аудите финансового показателя проверять тройку «доменная/презентационная политика → аргументы из host → итоговый форматтер». При реализации добавить проверки одинакового смысла за одинаковый период и знаков результата, не копировать формулу в тест только ради совпадения.
