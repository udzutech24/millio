# Design System - Millio

Визуальный стиль и правила дизайна приложения Millio.

## Общие принципы

### Темная тема (Dark Only)
- Приложение **всегда** использует темную тему
- Светлая тема **запрещена**
- Все экраны имеют единый градиентный фон

### Цветовая палитра

#### Фоновый градиент
Все экраны используют единый градиентный фон:
- **Верх:** `Color(red: 0.1, green: 0.2, blue: 0.35)` - темно-синий
- **Середина:** `Color(red: 0.15, green: 0.25, blue: 0.4)` - сине-зеленый
- **Низ:** `Color(red: 0.2, green: 0.15, blue: 0.3)` - темно-фиолетовый

Направление: сверху вниз (`.top` → `.bottom`)

#### Цвета текста
- **Основной:** `Color.white` - для заголовков и важного текста
- **Вторичный:** `Color.white.opacity(0.9)` - для подзаголовков
- **Третичный:** `Color.white.opacity(0.7)` - для вспомогательного текста

#### Градиенты для сервисов
Каждый сервис имеет свой уникальный градиент:

| Сервис | Градиент |
|--------|----------|
| Финансы | Blue → Cyan |
| Курсы | Green → Mint |
| Кешбэк | Purple → Pink |
| Кредиты | Blue → Indigo |
| Вода | Cyan → Blue |
| Привычки | Indigo → Purple |
| Картотека | Orange → Brown |
| Игры | Green → Cyan |

#### Градиенты для действий
- **Расход:** Purple → Pink
- **Доход:** Blue → Cyan

## Компоненты

### ServiceButton
Кнопка сервиса с градиентной обводкой.

**Стиль:**
- Фон: `.ultraThinMaterial` (полупрозрачный)
- Обводка: градиент (1.5pt)
- Скругление: 16pt
- Отступы: 20pt горизонтально, 16pt вертикально
- Иконка: 24pt, градиентный цвет
- Текст: 16pt, medium weight, белый
- Перенос текста: запрещен (`.lineLimit(1)`)

**Использование:**
```swift
ServiceButton(
    title: "Финансы",
    icon: "wallet.pass.fill",
    gradientColors: AppColors.financesGradient
) {
    // action
}
```

### ActionButton
Большая кнопка действия (Расход/Доход).

**Стиль:**
- Фон: `.ultraThinMaterial`
- Обводка: градиент (2pt)
- Скругление: 20pt
- Отступы: 24pt горизонтально, 18pt вертикально
- Иконка: в круге 32pt, белый фон с прозрачностью 0.2
- Текст: 18pt, semibold weight, белый
- Перенос текста: запрещен

**Использование:**
```swift
ActionButton(
    title: "Расход",
    icon: "minus",
    gradientColors: AppColors.expenseGradient
) {
    // action
}
```

### GradientBackground
Единый градиентный фон для всех экранов.

**Использование:**
```swift
ZStack {
    GradientBackground()
    // Ваш контент
}
```

## Типографика

### Заголовки
- **Большой заголовок:** 42pt, bold (название приложения)
- **Заголовок экрана:** 32pt, bold
- **Подзаголовок:** 28pt, bold
- **Секция:** 18pt, semibold

### Текст
- **Основной:** 16pt, regular/medium
- **Вторичный:** 16pt, regular, opacity 0.9
- **Мелкий:** 14pt, regular, opacity 0.7

### Кнопки
- **ServiceButton:** 16pt, medium
- **ActionButton:** 18pt, semibold
- **Обычная кнопка:** 16pt, semibold

## Отступы и размеры

### Стандартные отступы
- **Экранные отступы:** 24pt
- **Между элементами:** 16pt
- **Внутри кнопок:** 20-24pt горизонтально, 16-18pt вертикально

### Скругления
- **Кнопки сервисов:** 16pt
- **Кнопки действий:** 20pt
- **Карточки:** 20pt
- **Иконки в круге:** 32pt диаметр

## Иконки

### SF Symbols
Используются системные иконки SF Symbols.

**Размеры:**
- В кнопках сервисов: 24pt
- В кнопках действий: 16pt (в круге 32pt)
- В header: 28pt

**Цвета:**
- На градиентном фоне: градиент (соответствует кнопке)
- На кнопках действий: белый
- В header: белый

## Интерактивность

### Состояния кнопок
- **Normal:** стандартный вид
- **Pressed:** легкое затемнение (системное)
- **Disabled:** снижение opacity до 0.5

### Анимации
- Плавные переходы между экранами
- Легкие анимации при нажатии
- Использование системных анимаций SwiftUI

## Правила использования

### ✅ Можно
- Использовать градиенты для акцентов
- Применять `.ultraThinMaterial` для фонов элементов
- Использовать белый текст на градиентном фоне
- Добавлять новые градиенты для новых сервисов через `AppColors`

### ❌ Нельзя
- Использовать светлую тему
- Использовать плоские цвета вместо градиентов для акцентов
- Менять основной градиент фона
- Использовать цвета, не определенные в `AppColors`
- Разрешать перенос слов в кнопках

## Расширение

При добавлении новых сервисов:
1. Добавьте градиент в `AppColors` (например, `newServiceGradient`)
2. Используйте его в `ServiceButton`
3. Обновите эту документацию

## Примеры

### Создание нового экрана
```swift
struct NewServiceView: View {
    var body: some View {
        ZStack {
            GradientBackground()
            
            VStack {
                Text("Новый сервис")
                    .font(.system(size: 32, weight: .bold))
                    .foregroundStyle(AppColors.textPrimary)
            }
        }
        .navigationTitle("Новый сервис")
        .navigationBarTitleDisplayMode(.inline)
    }
}
```

### Создание кнопки с кастомным градиентом
```swift
ServiceButton(
    title: "Новый сервис",
    icon: "star.fill",
    gradientColors: [Color.yellow, Color.orange] // или AppColors.newServiceGradient
) {
    // action
}
```
